# Документация к текстовому редактору Bce

`Bce` — это легковесный и быстрый текстовый веб-редактор кода, построенный на базе стандартного HTML-атрибута `contenteditable`. Он поддерживает базовую подсветку HTML-тегов, автоотступы, историю изменений (Undo/Redo), работу с клавиатурными комбинациями и Emmet-сокращения.

---

## 🚀 Быстрый старт

Для инициализации редактора создайте HTML-контейнер и передайте его в конструктор класса:

```html
<!-- Контейнер для редактора -->
<div id="editor-container"></div>

<script>
  // Инициализация с базовыми настройками
  const editor = new Bce("#editor-container", {
    showLineNumbers: true,
    tabSize: 4,
    enableEmmet: true,
    initialText: "<h1>Привет, Мир!</h1>\n<!-- Это комментарий -->",
  });

  // Подписка на изменения текста
  editor.onChange((ed) => {
    console.log("Текст изменен! Текущая длина:", ed.getText().length);
  });
</script>
```

---

## ⚙️ Настройки (BceOptions)

При создании экземпляра класса вторым аргументом можно передать объект с настройками:

| Параметр          | Тип       | По умолчанию | Описание                                                 |
| :---------------- | :-------- | :----------- | :------------------------------------------------------- |
| `tabSize`         | `number`  | `4`          | Размер табуляции в количестве пробелов.                  |
| `initialText`     | `string`  | `""`         | Начальный текст, который заполнит редактор при загрузке. |
| `showLineNumbers` | `boolean` | `false`      | Показывать или скрывать левую панель с номерами строк.   |
| `enableEmmet`     | `boolean` | `false`      | Включить или выключить поддержку Emmet-сокращений.       |

## 🛠️ API Методы

### Управление текстом

- **`getText()`** — Возвращает всё текущее текстовое содержимое редактора (строки объединены через `\n`).
- **`setText(text)`** — Полностью заменяет текущий текст в редакторе на новый.
- **`setLines(lines)`** — Заменяет содержимое редактора массивом готовых объектов строк вида `[{ id: number, row: string }]`.
- **`setLineIdCounter(num)`** — Устанавливает счетчик id в ручную.
- **`areNotEqual(lines)`** — Сравнивает переданный массив строк с текущим состоянием редактора. Возвращает `true` когда массивы разные.
- **`Bce.Ne(arr1, arr2)`** — Статический метод. Сравнивает два массива. Возвращает `true` когда массивы разные.

### Статические методы

- **`Bce.equalLines(arr1, arr2)`** — Сравнивает два массива объектов строк. Возвращает `true`, если массивы идентичны по длине, тексту (`row`) и идентификаторам (`id`), иначе — `false`.

### Динамическое изменение настроек

- **`setShowLineNumbers(show)`** — Динамически включает (`true`) или выключает (`false`) отображение номеров строк на панели.
- **`setEnableEmmet(enable)`** — Переключает активность Emmet-аббревиатур.

### Интеграция и события

- **`onChange(callback)`** — Позволяет подписаться на любые изменения в редакторе. Функция `callback` принимает экземпляр редактора.

### История и манипуляции (продвинутые)

- **`undo()`** / **`redo()`** — Шаг назад и шаг вперёд по истории изменений.
- **`insertText(text)`** — Вставляет переданную строку в текущую позицию курсора (с учётом выделений).

## ⌨️ Горячие клавиши (Key Bindings)

В редактор встроена поддержка стандартных комбинаций клавиш для продуктивной работы:

- `Ctrl + C` — Копировать выделенный текст.
- `Ctrl + Z` — Отменить последнее действие (Undo).
- `Ctrl + Shift + Z` — Повторить отмененное действие (Redo).
- `Alt + Shift + ArrowDown` — Продублировать текущую строку вниз.
- `Alt + Shift + ArrowUp` — Продублировать текущую строку вверх.
- `Alt + ArrowDown` — Переместить текущую строку на одну позицию вниз.
- `Alt + ArrowUp` — Переместить текущую строку на одну позицию вверх.
- `Tab` — Увеличить отступ строки / вставить пробелы.
- `Shift + Tab` — Уменьшить отступ строки.

---

## 🪄 Поддержка Emmet

Если опция `enableEmmet` включена, вы можете написать сокращение и нажать клавишу `Tab` или `,` (запятую) для его автоматического развертывания:

- `a` ➡️ `<a href="..."></a>`
- `aa` ➡️ `<a href="..." target="_blank"></a>`
- `pre` ➡️ `<pre></pre>`
- `code` ➡️ `<code></code>`
- `h1` / `h2` / `h3` ➡️ соответствующий HTML-заголовок
