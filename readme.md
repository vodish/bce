# Документация к текстовому редактору Bce

`Bce` — это легковесный и быстрый текстовый веб-редактор кода, построенный на базе стандартного HTML-атрибута `contenteditable`. Он поддерживает базовую подсветку HTML-тегов, автоотступы, историю изменений (Undo/Redo), работу с клавиатурными комбинациями и Emmet-сокращения.

---

## 🚀 Быстрый старт

Для инициализации редактора создайте HTML-контейнер и передайте его в конструктор класса:

```html
<!-- Контейнер для редактора -->
<div id="editor-container"></div>

<script>
  // Инициализация с базовыми настройками
  const editor = new Bce("#editor-container", {
    showLineNumbers: true,
    tabSize: 4,
    enableEmmet: true,
    initialText: "<h1>Привет, Мир!</h1>\n<!-- Это комментарий -->",
  });

  // Подписка на изменения текста
  editor.onChange((ed) => {
    console.log("Текст изменен! Текущая длина:", ed.getText().length);
  });
</script>
```

---

## ⚙️ Настройки (BceOptions)

При создании экземпляра класса вторым аргументом можно передать объект с настройками:

| Параметр          | Тип       | По умолчанию | Описание                                                 |
| :---------------- | :-------- | :----------- | :------------------------------------------------------- |
| `tabSize`         | `number`  | `4`          | Размер табуляции в количестве пробелов.                  |
| `initialText`     | `string`  | `""`         | Начальный текст, который заполнит редактор при загрузке. |
| `showLineNumbers` | `boolean` | `false`      | Показывать или скрывать левую панель с номерами строк.   |
| `showRecId`       | `boolean` | `false`      | Показывать ID строк в гуттере вместо номеров.            |
| `enableEmmet`     | `boolean` | `false`      | Включить или выключить поддержку Emmet-сокращений.       |

## 🛠️ API Методы

### Управление текстом

- **`getText()`** — Возвращает всё текущее текстовое содержимое редактора (строки объединены через `\n`).
- **`setText(text, { resetHistory = false })`** — Полностью заменяет текущий текст в редакторе на новый. Курсор устанавливается в начало документа. С опцией `resetHistory: true` очищает историю undo/redo (по умолчанию старый документ доступен через Ctrl+Z).
- **`setLines(lines, { resetHistory = false })`** — Заменяет содержимое редактора массивом готовых объектов строк вида `[{ id: number, val: string }]`. Курсор устанавливается в начало документа. С опцией `resetHistory: true` очищает историю undo/redo.
- **`getLines()`** — Возвращает **копию** массива строк (мутация результата не влияет на редактор). Пустой редактор возвращает `[]`.
- **`setSequencer(num)`** — Устанавливает счетчик id в ручную.
- **`notEqual(lines)`** — Сравнивает переданный массив строк с текущим состоянием редактора. Возвращает `true` когда массивы разные.
- **`Bce.Ne(arr1, arr2)`** — Статический метод. Сравнивает два массива. Возвращает `true` когда массивы разные.

### Динамическое изменение настроек

- **`setShowLineNumbers(show)`** — Динамически включает (`true`) или выключает (`false`) отображение номеров строк на панели.
- **`setShowRecId(show)`** — Включает/выключает отображение ID строк в гуттере.
- **`setEnableEmmet(enable)`** — Переключает активность Emmet-аббревиатур.

### Emmet-сокращения

- **`addEmmet(key, template)`** — Добавляет/переопределяет сокращение. Шаблон — HTML со символом `|` в позиции курсора после разворота, например `editor.addEmmet("div", "<div>|</div>")`.
- **`removeEmmet(key)`** — Удаляет сокращение.

### Интеграция и события

- **`onChange(callback, { immediate = false })`** — Подписка на любые изменения в редакторе. Функция `callback` принимает экземпляр редактора.

> ⚠️ **Breaking change:** по умолчанию колбэк **не** вызывается в момент подписки (раньше вызывался немедленно — это могло приводить к рекурсии, если подписчик вызывал `setText` внутри колбэка). Для старого поведения передайте `{ immediate: true }`.

### Жизненный цикл

- **`destroy()`** — Полностью уничтожает редактор: снимает все обработчики (через AbortController), очищает контейнер и внутреннее состояние. Обязательно вызывайте перед выбросом экземпляра (SPA-навигация). Повторный `new Bce(container)` на том же контейнере автоматически уничтожает предыдущий экземпляр.

### История и манипуляции (продвинутые)

- **`undo()`** / **`redo()`** — Шаг назад и шаг вперёд по истории изменений.
- **`insertText(text)`** — Вставляет переданную строку в текущую позицию курсора (с учётом выделений, поддерживает многострочность).

## 🔄 Изменения в API (breaking changes)

| Изменение | Было | Стало |
| :-------- | :--- | :---- |
| `onChange(fn)` | Колбэк вызывался сразу при подписке | Вызывается только при изменениях; немедленный вызов — `onChange(fn, { immediate: true })` |
| `getLines()` | Возвращал внутренний массив строк | Возвращает копию `[{ id, val }]`; пустой редактор — `[]` |
| `setText` / `setLines` | Курсор не сбрасывался, история сохранялась | Курсор в начало документа; опция `{ resetHistory: true }` для очистки истории |
| `getSelectedText` | Выделение до начала строки N возвращало лишний `\n` | Хвостовой `\n` не добавляется при `endCol === 0` |

Также добавлены: защита от IME-композиции (китайский/японский ввод), drag & drop как plain text, фолбэк-копирование без `navigator.clipboard` (например, в iframe), кэш подсветки синтаксиса и инкрементальный рендер (плавная работа на документах в тысячи строк), сохранение позиции скролла при рендере, клампинг невалидных индексов в `setCursor`, `destroy()` + защита от двойной инициализации.

## ⌨️ Горячие клавиши (Key Bindings)

В редактор встроена поддержка стандартных комбинаций клавиш для продуктивной работы:

- `Ctrl + C` — Копировать выделенный текст.
- `Ctrl + Z` — Отменить последнее действие (Undo).
- `Ctrl + Shift + Z` — Повторить отмененное действие (Redo).
- `Alt + Shift + ArrowDown` — Продублировать текущую строку вниз.
- `Alt + Shift + ArrowUp` — Продублировать текущую строку вверх.
- `Alt + ArrowDown` — Переместить текущую строку на одну позицию вниз.
- `Alt + ArrowUp` — Переместить текущую строку на одну позицию вверх.
- `,>` — Если перед курсором стоит запятая: перемещает текущую строку на одну позицию вниз (запятая остаётся, `>` не вставляется).
- `,<` — Если перед курсором стоит запятая: перемещает текущую строку на одну позицию вверх (запятая остаётся, `<` не вставляется).
- `Tab` — Увеличить отступ строки / вставить пробелы.
- `Shift + Tab` — Уменьшить отступ строки.

## 🪄 Поддержка Emmet

Если опция `enableEmmet` включена, вы можете написать сокращение и нажать клавишу `Tab` или `,` (запятую) для его автоматического развертывания:

- `a` ➡️ `<a href="..."></a>`
- `aa` ➡️ `<a href="..." target="_blank"></a>`
- `pre` ➡️ `<pre></pre>`
- `code` ➡️ `<code></code>`
- `h1` / `h2` / `h3` ➡️ соответствующий HTML-заголовок

Свои сокращения добавляются через `editor.addEmmet(key, template)` и удаляются через `editor.removeEmmet(key)`.
